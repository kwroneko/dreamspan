# Initials font

`IBMPlexSansCondensed-Bold.ttf` is the unmodified IBM Plex Sans Condensed Bold
font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexsanscondensed).
It is distributed under the SIL Open Font License 1.1; see `OFL.txt`.

The placeholder portrait renderer passes this file directly to sharp's text input.
The worker build copies this directory beside the bundled format worker, including
its license. Rendering needs no fonts installed on the host.
